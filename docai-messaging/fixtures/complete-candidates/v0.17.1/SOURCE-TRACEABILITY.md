# Source Traceability — Incomplete Audit

This audit covers the `0.17.1` complete candidate's `full/` and `compact/` roots. JSON locations are JSON Pointers relative to the named source. The five prerequisite gaps recorded below have been addressed with explicit synthetic-source facts and projection tests. The full audit and release gate remain incomplete; this file does **not** certify release readiness.

## Authority and Checker Boundary

The authoritative input set is the four sources bound by `source/projection-input-manifest.json`: `storefront.asyncapi.json`, `storefront-behavior.json`, `complete-contexts.json`, and `complete-representations.json`. The manifest establishes perspective, precedence, adapter mappings, and projection identity. Existing output and literal test expectations are evidence of current rendering, not additional source authority.

`tools/check-complete-fixtures.mjs` validates document structure, identity, and full/compact equivalence. For this versioned candidate it also checks the exact bytes of all four manifest-declared source files and selected source-to-output facts in both profiles. `tools/tests/complete-candidate.test.mjs` checks further source bindings and projected facts. None of these checks proves that every emitted semantic fact has authoritative support. A matching pair can repeat the same unsupported assertion in both profiles.

`tools/tests/complete-source-projection.test.mjs` compares synthetic source identities, payload absence, scoped operation defaults, purposes, expanded Workflow coordination facts, and explicit variant schemas against parsed output in both profiles, expanding compact forms first. It checks closed roots independently of pair equality and verifies rejection of extra decoded properties in CSV and variant examples. The candidate-specific CLI audit repeats the directly comparable facts as a read-only gate, with additional manifest source-byte, perspective, version, Sources catalog row/provenance, storefront operation route/summary/identity/purpose, and twelve CONVENTIONS section checks. It is not a general source-aware converter.

The CLI gate deliberately does not yet compare every source fact. The other three storefront CONVENTIONS sections (Error Handling, Request-Reply, and Schema Evolution), all header/payload schema cells and examples, incomplete Workflow state meanings, exact Reference Material normalization, representation selection rules, compact reduction policy, and convention dependency closure still require fact-by-fact review and further source-aware checks. The twelve checked sections are Environments, Protocols and Bindings, Authentication, Serialization, Message Envelope, Delivery Semantics, Idempotency and Deduplication, Connection and Session, Ordering, Data Representation, Empty and Omitted Values, and Rate Limits and Quotas. Their comparison covers complete section content or exact parsed table rows with no trailing prose, not just the presence of a source keyword. Environments, Protocols and Bindings, and Serialization additionally compare the corresponding AsyncAPI and behavior facts, including the selected messages' media types. Authentication compares behavior's scheme, acquisition, rotation, and operation authorization with each AsyncAPI operation's OAuth2 client-credentials flow, token URL, and selected scopes; it does not yet certify every operation-body authorization claim. Candidate-specific prose normalization must be reviewed with any deliberate source wording change. The Sources `source_refs` check is exact for this four-source scenario, in which each catalog row is supplied by its own source; it is not a general rule that forbids cross-source catalog-cell contributors. Passing the gate is not a release-readiness certificate.

The earlier Core [source audit](../../core/v0.17.1/SOURCE-TRACEABILITY.md) documents the storefront contract mappings. Its two input files are retained in this candidate. Its Core-specific claims about source array positions, flat routing, empty contexts, all-file completeness, and `source_refs: all` do not transfer to this candidate.
