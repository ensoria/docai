# valid: multipart boundary delegation

Expected: valid complete conformance. Multipart documentation states the media type, includes a realistic sample, documents file-part requirements, and tells callers to delegate boundary construction.

````markdown
#### Body

**body_required**: yes

**media_type**: multipart/form-data

**body_nullable**: no

```http
Content-Type: multipart/form-data; boundary=<generated by HTTP library>

--<boundary>
Content-Disposition: form-data; name="document"; filename="statement.pdf"
Content-Type: application/pdf

<binary PDF bytes, maximum 10485760 bytes>
--<boundary>--
```

The caller must delegate multipart boundary construction to the HTTP library and must not hard-code the sample boundary token.

| Field | Type | Required | Nullable | Constraints / Meaning |
|---|---|---|---|---|
| document | file | yes | no | Multipart part name `document`; filename is required and must preserve the file extension; accepted part Content-Type values are `application/pdf` and `image/png`; maximum size is 10485760 bytes |
````
